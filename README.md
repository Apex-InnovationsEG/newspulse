# NewsPulse

A private news reader for Windows, by [Apex Innovations](https://apex-innovationseg.github.io/).

- Website: https://apex-innovationseg.github.io/newspulse/
- Latest installer: https://github.com/Apex-InnovationsEG/newspulse/releases/latest/download/NewsPulse-Setup.exe

This repo holds the NewsPulse web page (`main` branch, served by GitHub Pages) and the installer releases.

## Publishing a new version

On the `release-files` branch, replace `NewsPulse-Setup.exe` and update `VERSION`, then push. The workflow creates the release `v<VERSION>` and the download link above switches to it automatically.
